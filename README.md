# MIRNURI OFFICE 메인 페이지 시안

사무용품 판매에 맞춰 제작한 심플·미니멀 반응형 메인 페이지입니다.

## 구성

- `index.html` — 메인 페이지 구조와 카페24용 링크
- `styles.css` — 데스크톱/태블릿/모바일 반응형 스타일
- `script.js` — 모바일 메뉴, 검색, 장바구니 패널과 담기 피드백
- `assets/` — 웹 최적화된 히어로 및 상품 이미지

## 미리보기

`index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리를 사용하지 않아 별도 설치 과정이 없습니다.

## 카페24 적용 전 확인

이 폴더의 결과물은 디자인과 상호작용을 확인하는 독립형 시안입니다. 실제 쇼핑몰에 적용할 때는 현재 사용 중인 스킨을 복사해 백업한 후 진행하세요.

- 헤더, 푸터, 메인 페이지 영역을 현재 스킨의 레이아웃 파일에 나누어 반영
- `assets/` 이미지를 스킨 파일 영역에 업로드하고 이미지 경로 변경
- 정적 상품 카드 4개를 카페24 메인 상품진열 모듈로 교체
- 상품 가격, 재고, 할인율, 장바구니 담기는 카페24 상품 모듈 데이터와 연결
- PC와 모바일이 서로 다른 스킨이면 양쪽에 각각 반영

현재 페이지의 카테고리, 로그인, 게시판 링크는 기존 미르누리 쇼핑몰 경로를 기준으로 연결되어 있습니다.
